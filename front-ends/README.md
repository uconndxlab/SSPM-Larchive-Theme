# sing-sing-museum

This directory contains the original static front-end used for design reference.

Canonical Blade templates for the Larchive theme live under:

- `front-ends/views/`  — Blade `views` and `layouts` that Larchive will load when the theme is active

Do not edit the top-level static HTML files when changing theme templates — modify files in `front-ends/views/` instead.
